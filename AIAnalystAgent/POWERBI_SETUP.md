# Power BI Integration Setup Guide

This guide will help you set up Power BI integration for automated report generation and emailing.

## Prerequisites

1. **Power BI Premium or Pro Account** (Pro = personal dashboards, Premium = enterprise sharing)
2. **Azure AD Account** (for authentication)
3. **Python packages**: `openpyxl`, `pandas`, `requests` (already in requirements.txt)

---

## Step 1: Create an Azure AD App Registration

### In Azure Portal:

1. Go to **Azure Active Directory** > **App registrations** > **New registration**
2. Fill in:
   - **Name**: `AI Analyst Pipeline`
   - **Supported account types**: `Accounts in this organizational directory only`
3. Click **Register**
4. Note these values:
   - **Application (client) ID** → save as `POWERBI_CLIENT_ID`
   ef38806f-98f8-43f7-9d99-a8fad7cd4a27
   - **Directory (tenant) ID** → save as `POWERBI_TENANT_ID`
   a0e457a9-a07d-4859-bb97-9686fc555720

### Add Client Secret:

1. Go to **Certificates & secrets** > **New client secret**
2. Click **Add**
3. Copy the **Value** → save as `POWERBI_CLIENT_SECRET`
ag68Q~UHNu4ndCbOVOn6Fmtv2hVl_wWABkvSJdpz
   - ⚠️ **This only shows once! Save it immediately**

### Grant Power BI API Permissions:

1. Go to **API permissions** > **Add a permission**
2. Select **Power BI Service**
3. Select **Delegated permissions** (or **Application permissions** if using app-only auth)
4. Check:
   - ✓ `Dataset.ReadWrite.All`
   - ✓ `Report.Read.All`
5. Click **Grant admin consent**

## Step 2: Create Power BI Workspace and Dataset

### Create Workspace:

1. Log into **app.powerbi.com**
2. Click **Workspaces** > **Create a workspace**
3. Name it (e.g., `AI Analyst`)
4. Note the workspace URL: `https://app.powerbi.com/groups/{workspace-id}/...`
   - Extract the GUID after `/groups/` → save as `POWERBI_WORKSPACE_ID`
   37a505ce-35f8-4d92-b373-7ad91f1f566b

### Create Empty Dataset:

1. In the workspace, click **+ New** > **Dataset**
2. Choose **Excel Online (Recommended)**
3. Upload the `analysis_export.xlsx` file (generated by the pipeline)
4. Create dataset from it
5. Once created, go to **Settings** > **Dataset settings**
6. Copy the **Dataset ID** from the URL bar
   - Save as `POWERBI_DATASET_ID`
   2e689538-1a94-48d7-a756-9c73002e3ecb

### Create a Report from Dataset:

1. Go to the dataset > **Create report**
2. Design your dashboard with visualizations (or keep default)
3. Save the report
4. Copy the **Report ID** from the URL:
   - Example: `app.powerbi.com/.../reports/{report-id}/...`
   - Save as `POWERBI_REPORT_ID`
   34f0585a-a1f7-4349-a5c9-9275c9e7cb2d

## Step 3: Set Environment Variables

### PowerShell (Windows):

```powershell
# Power BI Configuration
$env:POWERBI_CLIENT_ID = "YOUR_CLIENT_ID"
$env:POWERBI_CLIENT_SECRET = "YOUR_CLIENT_SECRET"
$env:POWERBI_TENANT_ID = "YOUR_TENANT_ID"
$env:POWERBI_WORKSPACE_ID = "YOUR_WORKSPACE_ID"
$env:POWERBI_DATASET_ID = "YOUR_DATASET_ID"
$env:POWERBI_REPORT_ID = "YOUR_REPORT_ID"

# Email Configuration (from previous setup)
$env:EMAIL_SENDER = "your-email@gmail.com"
$env:EMAIL_PASSWORD = "your-16-char-app-password"
$env:CEO_EMAIL = "ceo@example.com"
$env:DATA_PATH = "path/to/Online Retail.xlsx"
```

### Bash/Linux/Mac:

```bash
export POWERBI_CLIENT_ID="YOUR_CLIENT_ID"
export POWERBI_CLIENT_SECRET="YOUR_CLIENT_SECRET"
export POWERBI_TENANT_ID="YOUR_TENANT_ID"
export POWERBI_WORKSPACE_ID="YOUR_WORKSPACE_ID"
export POWERBI_DATASET_ID="YOUR_DATASET_ID"
export POWERBI_REPORT_ID="YOUR_REPORT_ID"
export EMAIL_SENDER="your-email@gmail.com"
export EMAIL_PASSWORD="your-16-char-app-password"
export CEO_EMAIL="ceo@example.com"
export DATA_PATH="path/to/Online Retail.xlsx"
```

### Make it Permanent (PowerShell):

Create a file `setup_env.ps1`:

```powershell
# setup_env.ps1
$env:POWERBI_CLIENT_ID = "YOUR_CLIENT_ID"
$env:POWERBI_CLIENT_SECRET = "YOUR_CLIENT_SECRET"
# ... rest of vars
```

Run before each session:
```powershell
. .\setup_env.ps1
```

## Troubleshooting

### ❌ "Missing required Power BI environment variables"
- Check all 6 variables are set correctly
- Verify no typos in IDs

### ❌ "Authentication failed"
- Verify `POWERBI_CLIENT_SECRET` is correct (regenerate if needed)
- Ensure app has Power BI API permissions granted

### ❌ "Failed to push data"
- Verify `POWERBI_DATASET_ID` is correct
- Check Power BI dataset is empty (not already populated)
- Verify data format matches dataset schema

### ❌ "Email not sent"
- Verify `EMAIL_SENDER` and `EMAIL_PASSWORD` are correct
- For Gmail: ensure 2FA is enabled and app password is used
- Check `CEO_EMAIL` is valid

## How It Works

1. **Pipeline runs** (weekly on Monday 07:00 or with `--now`)
2. **Analysis runs** (sales, products, churn, anomalies)
3. **Data exported** to Excel (`analysis_export.xlsx`)
4. **Power BI dataset refreshed** with new data
5. **Excel attached** to email
6. **Power BI link included** in email body
7. **CEO clicks link** to view interactive dashboard
